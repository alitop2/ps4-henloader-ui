PS4 HenLoader Web UI
====================

هذه الحزمة عبارة عن واجهة HTML/CSS/JS فقط.

الملفات:
- index.html  : الصفحة
- style.css   : التصميم
- script.js   : التفاعلات
- images/logo.svg : الشعار التجريبي

لتغيير الشعار:
استبدل images/logo.svg بصورةك، ثم غيّر src في index.html إذا كان اسم الملف مختلفًا.

مهم:
هذه الواجهة لا تحتوي على استغلال PS4 أو Payload/Jailbreak فعلي.
